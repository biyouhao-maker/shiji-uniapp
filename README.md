# 时记 - uni-app 版

时记是一款时间追踪应用，帮助用户记录和管理项目时间。基于 uni-app 框架，支持多端运行。

## 功能

- **首页** - 快速记录时间，查看今日概览
- **项目管理** - 创建、编辑、删除项目
- **项目详情** - 查看单个项目的时间记录
- **日视图** - 按天查看时间分配
- **历史记录** - 浏览历史时间记录
- **统计分析** - 可视化时间使用情况（日/周/月）
- **个人中心** - 用户设置与信息

## 支持平台

| 平台 | 状态 | 说明 |
|------|------|------|
| H5 网页 | ✅ | 浏览器直接访问 |
| PWA | ✅ | 可添加到主屏幕 |
| 微信小程序 | ✅ | 需配置 appid |
| Android App | 📦 | HBuilderX 打包 |

## 开发

1. 安装依赖：`npm install`
2. 运行 H5：`npm run dev:h5`
3. 构建 H5：`npm run build:h5`
